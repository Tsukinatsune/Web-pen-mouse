# 🎨 Studio Chat Template Guide

## How to prepare your template

### Main File Requirement (Very Important)
This main file will be **`studioChat.html`** by to load the overlay

---

```
Your github
├── studioChat.html
├── preview/
│   ├── 01.png
│   └── 02.png
├── thumbnail.png
└── README.md
```
Just name your main file **`csctsukinatsune.html`**
Example:
csctsukinatsune.html Will be renamed to studioChat.html

### Important Notes

- Only **one** file will be renamed to `studioChat.html`
- All other files (images, scripts, CSS, etc.) keep their original names and folder structure
- Recommended to put your main file inside a folder
- Make sure `studioChat.html` is a complete standalone custom chat
